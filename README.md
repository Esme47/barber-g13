# BARBER G13
Sistema profesional para barbería: agenda, reservas, clientes, servicios, finanzas y WhatsApp.

## Inicio
1. Copia `.env.example` como `.env.local`.
2. Agrega credenciales de Supabase.
3. `npm install`
4. `npm run dev`

## Deploy
Sube esta carpeta al repositorio `Esme47/barber-g13`, luego impórtalo en Vercel y agrega las variables de entorno.
